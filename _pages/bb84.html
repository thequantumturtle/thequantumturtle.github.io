Step 3 · Compare bases

Which bits survive?

Keep a round only when Alice and Bob chose the same basis. If their bases differ, discard that round.

Candidate shared key

In real BB84, Alice and Bob publicly compare a random sample of surviving bits to estimate errors, discard that sample, then use error correction and privacy amplification. This short demo shows all results to explain the idea. The displayed bits are not a secure cryptographic key.

Why does this work?

In the + basis, bit 0 is |0⟩ and bit 1 is |1⟩. In the × basis, bit 0 is |+⟩ and bit 1 is |−⟩.

When Bob uses Alice's basis, he gets her bit with certainty in the ideal model. With the wrong basis, he gets 0 or 1 with equal chance. Eve cannot measure an unknown quantum state without sometimes changing it.

With an ideal intercept-resend attack, Eve causes an average error rate of 25% among the bits whose bases match. Small experiments vary because measurements are random.

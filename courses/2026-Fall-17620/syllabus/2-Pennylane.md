## Session overview

- Set up a PennyLane programming environment
- Build quantum circuits with parameterized gates and observables
- Compute gradients using `qml.grad`
- Compare circuit syntax in PennyLane, Qiskit, and Cirq

**Take-home activity:** replicate a Bell-state experiment on a real quantum backend.

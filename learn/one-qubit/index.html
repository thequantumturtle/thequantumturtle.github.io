01 · From bits to qubits

Randomness alone does not give us a qubit.

Classical bit

A binary piece of information has a value of 0 or 1.

0

Probabilistic bit

One number describes the distribution: P(1) = p and P(0) = 1 − p.

Predict the counts before sampling.

Pure qubit

Two complex amplitudes describe the state:

|ψ⟩ = α|0⟩ + β|1⟩

α = a + bi   β = c + di

Four real coordinates introduce structure a probability distribution cannot capture: relative phase.

Four coordinates, two independent parameters

The state space is two-dimensional over complex numbers. Normalization requires |α|² + |β|² = 1, and global phase has no observable effect. A pure qubit therefore has two independent real parameters. These coordinates are not four independently readable values.

02 · Same probabilities, different states

What does the histogram leave out?

|+⟩ = (|0⟩ + |1⟩)/√2 and |−⟩ = (|0⟩ − |1⟩)/√2 give identical Z probabilities. A gate can make their difference observable.

State A · |+⟩

State B · |−⟩

Predict: could more Z measurements distinguish these preparations?

Explain the result

No number of Z measurements distinguishes these two preparations. H combines signed amplitudes: H|+⟩ = |0⟩ and H|−⟩ = |1⟩. The initial probabilities alone cannot predict both results.

03 · Build, predict, run

A small gate lab.

Choose a preparation, apply gates, and inspect the simulator’s state. Each sampled shot freshly prepares the final state shown here; sampling does not change the lab state.

Try these experiments
  1. Prepare |0⟩. Compare X–X and H–H. Both restore the original state.
  2. Prepare |+⟩ and |−⟩. Measure each in Z, then X.
  3. Prepare |+i⟩ and |−i⟩. Find the basis that distinguishes them.

Hardware measures Z after basis rotations: H for X; S† followed by H for Y.

04 · Discover the hidden state

What if the state display is unavailable?

Tomography estimates a state from three separate batches of freshly prepared qubits. It does not measure X, Y, and Z successively on one qubit.

⟨A⟩ ≈ (n₀ − n₁)/N   ·   ρ = ½(I + xX + yY + zZ)

Collect all three bases before revealing.

Why might the estimate lie outside the Bloch sphere?

Independent finite-shot estimates can produce x² + y² + z² greater than 1. That density matrix is not physical. We flag the raw estimate instead of silently normalizing it. More shots usually improve precision, but do not guarantee a physical estimate.

05 · Superposition or mixture?

A 50/50 histogram is not enough.

Prepare |+⟩ every time

Bloch vector (1, 0, 0). A pure state with a definite relative phase.

Choose |0⟩ or |1⟩ at random

Bloch vector (0, 0, 0). An equal mixture, ρ = I/2.

Predict: which basis distinguishes these preparations?

Answer

Both give 50/50 outcomes in Z. In X, |+⟩ always gives 0; the mixture still gives 50/50 outcomes. A mixed state generally cannot be represented by a single state vector.
